# 整份简历的结构

沿用原简历的阅读顺序。

1. **页首**。姓名下放一行联系方式和相关公开链接，随后用一行写学校、专业和毕业时间。开源身份、代表奖项或贡献高度相关时，可在页首加一行。熟练或资深候选人可把教育移到末尾。
2. **工作经历**。按最近到最早排列。每段先写公司、岗位、时间，再在其下放本人参与的项目。项目标题写清交付对象或产品。背景、指标与效果、我的职责按这个顺序组织。只写能核对的指标。职责用短标题拆分，每条写一个关键动作和交付。篇幅紧张时，把背景压成半句，把结果接在对应动作后。
3. **实习经历**。沿用工作经历结构。没有正式工作经历时，实习可作为主栏目。相关的长期兼职和独立接单可按真实身份放在此处或单列。
4. **AI 创业／独立项目**。放与目标岗位相关的完整项目，注明角色、交付阶段和可公开的演示或成果。避免与工作经历重复。
5. **开源、研究与奖项**。页首用一行提示最相关的可信信号。需要展开时放到独立栏目，补上项目或论文名称、具体贡献、奖项和年份。技能栏按需添加，仅保留与目标工作直接相关且有素材支撑的能力。

整份起草时，按上述顺序用已提供事实写齐可用栏目，省略空栏目。先给可以投递的草稿，待确认事实列在稿外。重组旧简历时，优先调整顺序、拆合栏目、移动重复内容和压缩低相关条目，沿用原有事实与语言，在成稿之后简述影响最大的结构变动。用户只要求调结构时，保留原句，必要的衔接可小改。

## 排版与交付

参考学术论文的单栏和清晰标题层级。采用黑白正文、适度留白、统一日期格式和克制的加粗。姓名和栏目名足够醒目。直接使用可复制的文本和链接，省去照片、图标、技能进度条、彩色背景、侧栏和论文式双栏。默认优先用一页呈现高相关经历，材料较多时可用两页保持可读字号。

用户明确要 LaTeX 或 PDF 时，读取同目录 Skill 所链接的 LaTeX 模板。写入完整的可编译源文件，按正文或链接所在语境正确处理 LaTeX 特殊字符。用 XeLaTeX 编译，检查分页、溢出、中文字体、链接和文本复制。缺少编译环境时，交付源文件并说明 PDF 尚未生成。英文简历可将文档类改为 `article` 并翻译栏目名。

For English resumes, use the same structure with **Work Experience**, **Internships**, **Independent AI Projects**, and optionally **Open Source, Research & Awards**. Within each project, use **Context**, **Impact**, and **Contributions** as space allows.

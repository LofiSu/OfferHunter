# AI 岗位证据参考

按目标岗位的实际工作选取对应的 STAR 素材。新职能可照样提取「为谁解决什么问题、负责哪项交付、如何验证」。

| 岗位方向 | 可写入 STAR 的交付或行动 | 可核对的结果与范围 |
| --- | --- | --- |
| AI 研究、应用科学 | 提出假设、复现基线、控制变量、完成消融或误差分析 | 实验条件、数据划分、对照结果、本人负责的研究环节 |
| 模型训练、算法工程 | 构建数据配方、实现训练策略、微调或优化模型 | 训练规模、基座与算力、离线评测和资源开销 |
| AI 应用、Agent、RAG、AI 前后端 | 设计检索或工具流程、构建交互、处理失败与人工接管 | 按任务统计的成功率、线上或离线口径、时延或用户采用 |
| 推理、ML 平台、MLOps | 优化批处理、部署与监控、自动回滚、管理模型版本 | 硬件、并发、输入规模、P95 时延、吞吐或单位成本 |
| AI 数据、标注和数据运营 | 设计标注规范、采集与清洗、建立质量抽检和反馈闭环 | 数据量、样本范围、一致性或缺陷变化 |
| 模型评测、质量和 AI 安全 | 设计评测集、覆盖失败场景、分析误判、验证防护措施 | 样本与评分标准、复现结论、加固前后证据 |
| 多模态、语音视觉、机器人 | 建立模态处理链路、融合传感器数据、做场景验证 | 测试场景、环境约束、设备或数据范围与失败模式 |
| AI 产品、设计、用户研究 | 定义用例和验收标准、设计交互与人工确认、验证工作流 | 调研发现、试点反馈、采用、任务完成或经验证的取舍 |
| AI 治理、合规和政策 | 定义风险分类与审查、组织评估、推动整改与复审 | 评估范围、流程采纳、审查产物或整改闭环 |
| 解决方案、售前、交付和开发者关系 | 澄清场景、组织 PoC、集成系统、完善文档或示例 | 验收范围、集成状态、使用反馈和本人参与阶段 |
| 技术管理、研究管理 | 明确技术路线、协调资源、建立交付或研究验证机制 | 决策范围、团队交付、进度与候选人的管理职责 |

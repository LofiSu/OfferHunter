# 项目经历怎么写

## EC-Monica 电商产运 Agent

- **情境**：电商产品、运营和研发需要查业务数据、分析指标波动的原因，并整理成报告。
- **任务**：作为项目负责人，从零搭建并上线电商产运 Agent，支持查数、报告生成、归因和需求文档解析。
- **行动**：实现意图识别和工具路由，让 Agent 按需查数、计算同比与环比，并逐轮汇总结论。加入调用重试和降级，用业务范文和摘要指导报告生成。
- **结果**：上线后月均调用 600+ 次，其中约 55% 为报告任务，约 45% 为需求与归因解析。单次分析报告原先人工编写需 1–2 小时，使用 Agent 生成需 5–15 分钟。

## AI 封面图生成工具

- **情境**：创作者在多个平台发布内容时，需要分别制作符合各平台尺寸的封面。
- **任务**：搭建封面图生成工具，让创作者选择平台、上传素材，生成可直接使用的封面。
- **行动**：用 Next.js 实现平台尺寸预设、主体上传和风格参考图输入。按平台和风格组织提示词，接入图像生成 API，并实现免费额度和订阅。
- **结果**：工具支持多平台封面生成、预览和下载，订阅用户可批量生成并导出高清图。

# 项目经历怎么写

## EC-Monica 电商产运 Agent

- **背景**：电商产品、运营和研发需要查业务数据、分析指标波动的原因，并整理成报告。
- **我的职责**：担任项目负责人，从零设计并上线电商产运 Agent，负责工具编排和模型上下文。
- **行动**：先识别意图，判断是直接生成还是调用工具。需要查数时，逐轮调用工具，计算同比、环比，再把阶段结论汇总成报告。为工具调用加入超时重试和降级。用业务范文统一报告格式，用摘要和滑动窗口保留前几轮的关键信息。
- **结果**：上线后月均调用 600+ 次，其中约 55% 为报告任务，约 45% 为需求与归因解析。单次分析报告原先人工编写需 1–2 小时，使用 Agent 生成需 5–15 分钟。

## AI 封面图生成工具

- **背景**：创作者在多个平台发布内容时，需要分别制作符合各平台尺寸的封面。
- **我的职责**：担任项目负责人，负责前端、支付与订阅，以及从素材上传到封面生成的完整流程。
- **行动**：用 Next.js 实现平台尺寸预设、主体上传和风格参考图输入。按平台和风格组织提示词，接入图像生成 API，并实现免费额度和订阅。
- **结果**：工具支持多平台封面生成、预览和下载，订阅用户可批量生成并导出高清图。
